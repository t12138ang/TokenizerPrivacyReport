# 文献检索与相关工作综述

## 1. 检索与真实性审计方法

本项目在 2026-07-26 进行定向检索，主题覆盖 Tokenizer/BPE 泄露、成员推断、差分隐私、隐私审计、安全聚合、Paillier 加法同态加密及下游文本分类。优先级依次为会议或期刊官方页面、出版社 DOI 页面、正式论文 PDF；arXiv 仅在 USENIX Security 2026 尚未发布最终页码时用于补充全文。没有使用二手博客生成 BibTeX。

结构化审计表见 `docs/LITERATURE_AUDIT.csv`，BibTeX 见 `paper/references.bib`。两者当前均为 38 条，citation key 一一对应。其中 16 条是 2024--2026 年 CCF A/B 会议论文，满足课程要求的“至少 15 篇”。2026 年条目只收录已经在 USENIX 或 NDSS 官方页面确认接收/发表的论文；未确认存在的题目不进入参考文献。

CCF 等级仅用于满足课程的检索范围约束，不代表本文对论文质量的重新评价。USENIX Security、IEEE S&P、ACM CCS、NDSS、NeurIPS、ICML、ICLR 按本项目采用的 CCF 目录记为 A；无法自然映射到 CCF 会议/期刊目录的专著记为 N/A。

## 2. Tokenizer 泄露与集合级成员推断

Tong 等人的工作直接定义了本文复现的五种 Tokenizer 成员推断攻击：压缩率、词表重叠、频率估计、合并相似度和朴素贝叶斯。该工作是本文的攻击基准，而不是本地结果来源；官方论文中的数值不得复制为本地实验结果。Hayase 等人从 BPE 合并顺序恢复训练混合比例，说明即便不访问语言模型参数，Tokenizer 本身也能泄露训练语料的宏观组成。二者共同支持“Tokenizer 是独立发布面”的研究动机。

Maini 等人指出 LLM 成员推断容易受成员/非成员分布漂移污染，并建议在数据集层面进行推断。本文据此采用固定 C4 revision、同源网站、严格互斥的 member/nonmember 划分，并报告集合级而非人为标记过的单文档结论。SPV-MIA、PANORAMIA、OSLO、Cascading/Proxy MIA 进一步说明校准、非成员构造、低 FPR 指标和 shadow 数量都会实质影响结论，因此本文预先固定分数方向，同时报告 ROC AUC、AP、Balanced Accuracy、TPR@1% FPR 和 TPR@0.1% FPR。

## 3. 防御不能由“传输加密”替代

Paillier 方案提供加法同态性和在判定复合剩余假设下的语义安全，可隐藏单客户端上传和未加噪聚合值；Bonawitz 等与 Bell 等的安全聚合工作提供了不同信任/故障模型下的替代路线。然而，SIGuard 以及成员推断基础文献共同说明，计算过程保密并不会自动限制最终发布输出泄露。因此本文明确区分：

1. HE-only 保护训练期频率机密性，但不为最终 Tokenizer 提供成员差分隐私；
2. 站点级 DP 约束最终可观察输出相对一个完整网站增删的分布变化；
3. 两服务器非共谋假设只覆盖当前原型，A 与 D 共谋可恢复未扰动聚合；
4. Min-count 是经验过滤，不等价于差分隐私。

本文未实现 Bonawitz 型掉线容错安全聚合，也未实现门限 Paillier；这些均作为可替换构件和后续方向讨论，不能写成当前系统已具备的性质。

## 4. 站点级差分隐私与离散计数

Dwork 等给出全局敏感度校准噪声的基本框架，Dwork--Roth 系统总结了邻接关系和顺序组合。本文的隐私单位是完整网站，采用 add/remove 邻接。每个客户端先用确定性最大余数法将候选词对频率向量截断到 L1 上界，再对整数计数使用双边几何噪声。基本组合直接给出总预算

\[
\varepsilon_{\mathrm{total}}=\sum_{r=1}^{R}\varepsilon_r,
\]

而不是只报告单轮预算。Kairouz 等的组合结果及 Mironov 的 RDP 提醒我们存在更紧的会计方法，但当前代码和论文都只声明已实现的基本顺序组合。Canonne 等讨论的离散高斯进一步说明整数机制需要避免浮点采样伪差分隐私；当前工作选择易于给出纯 DP 似然比界的双边几何分布，并把精确整数采样和溢出测试纳入审计。

## 5. BPE 效用与下游任务

Sennrich 等给出子词 BPE 在稀有词处理中的经典用法，SentencePiece 展示了语言无关的子词工程路径。本文在统一 held-out C4 网站与 AG News 文本上比较 bytes/token、characters/token、每句/每文档 token 数、稀有词切分和长尾覆盖，避免仅以目标词表大小代替真实效用。C4 的数据背景来自 Raffel 等，AG News 四分类口径沿用 Zhang 等的公开基准。

下游分类固定同一两层 Transformer Encoder、相同数据划分、优化器、最大 epoch、早停规则和三个随机种子。验证集只选择 epoch，测试集只在最佳验证检查点确定后评估一次。这样可以把差异更合理地归因于 Tokenizer，而不是为某个防御单独调参。

## 6. 与现有防御的关系及当前可主张范围

SOFT、Diffence、DOPPLER 等分别从数据选择/扰动、输入重生成和优化器降噪改善隐私--效用权衡；它们不直接解决公开 BPE 候选、逐站点截断和同态聚合的组合问题。本项目把这三个方面放进同一个原型并做四维评估，但在检索和最终实验完成前，不使用“首次”“最优”或“完全安全”等措辞。

当前文献能支持的是：Tokenizer 确实可能成为训练数据推断面；加密聚合和发布期成员隐私是不同目标；站点级邻接比 document-level 邻接更直接匹配网站成员推断。文献本身不能替代本文的本地攻击、效用、下游性能和 2048-bit Paillier 开销结果，所有这些数字必须来自 `results/final/` 的自动生成注册表。
