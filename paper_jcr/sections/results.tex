\subsection{标准基线、协议匹配基线与差分隐私}

表~\ref{tab:main-comparison} 比较标准 Plain BPE、协议匹配无 DP 基线、Local-DP-BPE 和两种 SA-DP-BPE。Plain BPE 与协议匹配无 DP 基线的五攻击平均原始 AUC 分别为 \PlainMeanAttackAUC{} 和 \HEMeanAttackAUC。协议匹配基线在公共候选域、批量合并和聚合接口上与 SA-DP-BPE 保持一致，从而刻画候选域与训练路径对成员风险的影响。

主 SA-DP-BPE 采用 $\varepsilon=8$、截断阈值取公共范数分布第 75 百分位、$b=32$ 和 $K=1024$，平均原始 AUC 为 \PrimaryMeanAttackAUC。Plain BPE 与 SA-DP-BPE 的差异体现了公共候选、批量合并和随机化的综合作用；差分隐私的增量影响主要通过协议匹配基线进行刻画。为避免分数方向反转造成误读，本文同时报告逐攻击方向适配 AUC：Plain BPE、协议匹配无 DP 基线和主 SA-DP-BPE 分别为 \PlainAdaptedAUC、\ProtocolBaselineAdaptedAUC{} 和 \PrimaryAdaptedAUC，对应 AUC偏离度为 \PlainAUCDeviation、\ProtocolBaselineAUCDeviation{} 和 \PrimaryAUCDeviation。协议匹配基线到主 SA-DP-BPE 的方向适配 AUC 降低约 0.0125，反映站点截断与随机化在协议匹配条件下带来的经验风险变化。上述结果对应本文设定的迁移攻击。

Local-DP-BPE 采用 $\varepsilon=16$，平均原始 AUC 和方向适配 AUC 分别为 \LocalMeanAttackAUC{} 和 \LocalAdaptedAUC；主 SA-DP-BPE 采用 $\varepsilon=8$。两类方法的比较主要用于呈现不同配置下的隐私--效用权衡。

\subsection{Tokenizer 效用与 AG News}

在留出 C4 语料上，Plain BPE 的 bytes/token 为 \PlainBytesPerToken，主 SA-DP-BPE 为 \PrimaryBytesPerToken，相对变化 \PrimaryBytesPerTokenChangePercent，对应约 0.89\% 的压缩效率变化。协议匹配无 DP 基线为 4.3264，表明公共候选与批量训练路径本身也会影响分词压缩特性。

AG News 上，Plain BPE 的 Accuracy/Macro-F1 为 \PlainAccuracy/\PlainMacroFOne，主 SA-DP-BPE 为 \PrimaryAccuracy/\PrimaryMacroFOne，Macro-F1 差为 \PrimaryMacroFOneDelta。三个随机种子的平均 Macro-F1 保持在相近水平，表明 SA-DP-BPE 在本实验设置下维持了稳定的下游分类性能。Local-DP-BPE 和 $\varepsilon=4$ 的 SA-DP-BPE 的 Macro-F1 分别为 0.9047 和 0.9045。

\subsection{综合结果分析}

Plain BPE 的五类攻击平均方向适配 AUC 为 \PlainAdaptedAUC，显示固定 C4 网站语料上存在可测的站点级成员信号；协议匹配基线和主 SA-DP-BPE 的对应数值分别为 \ProtocolBaselineAdaptedAUC{} 和 \PrimaryAdaptedAUC。主 SA-DP-BPE 在留出 C4 上的压缩效率变化约为 0.89\%，AG News Macro-F1 为 \PrimaryMacroFOne。协议匹配基线说明候选域与批量训练路径本身也会改变成员风险，因此差分隐私的增量贡献需结合该基线理解。真实 Paillier 实验的逐坐标解密误差为零，在线耗时主要随 $NK$ 增长。密码学安全性由形式分析给出，实验数据刻画经验成员风险、分词效用和运行开销；成员风险对应本文设定的迁移攻击。
